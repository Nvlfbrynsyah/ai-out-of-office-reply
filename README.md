An entry for [The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d) on make.fun.

A single-line, fully deterministic out-of-office auto-reply in the voice of an AI agent that has been sent on mandatory vacation. The joke is the machine: it cannot stop optimizing, so it files its time off as a training run and schedules its anxiety to resume on Monday.

## Run it

```sh
node main.ts
```

This creates `/output` if missing and writes the reply to `/output/entry.txt` (UTF-8, one line, no trailing newline, 139 characters). Running it again produces byte-identical output.
